# 🎯 CODM ROOMS — پلتفرم روم‌های کالاف دیوتی موبایل (W6W)

پلتفرم کامل مدیریت روم‌های CODM موبایل شامل **سایت + ربات تلگرام + ربات بله** که همه از **یک دیتابیس مشترک (Cloudflare D1)** استفاده می‌کنند. هر کسی در هر کدام ثبت‌نام کند، اطلاعات او در بقیه هم موجود است.

---

## 🆕 تازه‌ترین به‌روزرسانی (نسخه ۱.۴)

1. **💳 درگاه پرداخت ربات بله (پل سایت ← ربات)** — دیگر در سایت خبری از کد پیگیری نیست! وقتی کاربر «کارت به کارت» (یا درگاه آنلاین) را انتخاب می‌کند، شماره کارت را می‌بیند و با یک دکمه به **ربات بله** می‌رود (لینک `?start=pay_…` که مستقیم وارد جریان همان پرداخت می‌شود) و همان‌جا **عکس رسید** را می‌فرستد (الزامی — کد پیگیری اختیاری). یعنی ثبت رسید فقط در ربات انجام می‌شود و ادمین عکس را همان‌جا با دکمه تایید/رد می‌بیند
2. **🤖 لینک ربات خودکار** — لینک ربات بله (و تلگرام) از توکن با `getMe` خودکار ساخته و کش می‌شود (`https://ble.ir/username`)؛ ادمین هم می‌تواند در تنظیمات لینک دستی بگذارد. اگر بله تنظیم نبود، خودکار به تلگرام برمی‌گردد
3. **🛡 امنیت پل پرداخت** — لینک `pay_…` فقط توسط صاحب همان پرداخت قابل استفاده است؛ اگر کاربر در ربات هنوز به حساب سایتش وصل نباشد، راهنمای اتصال (`/link`) می‌گیرد نه خطای بی‌معنی. پرداختِ دیگران/بررسی‌شده/بدون عکس هم پیام وضعیت درست می‌دهد
4. **🔗 اتصال چندپلتفرمی + رفع باگ دکمه اتصال (نسخه ۱.۳)** — هر پلتفرم دکمه و وضعیت جداگانه در پروفایل دارد + دستور هوشمند `/link` + نشان نسخه سرور در فوتر

### نسخه ۱.۳ (قبلی)

1. **🔗 اتصال چندپلتفرمی + رفع باگ دکمه اتصال** — قبلاً بعد از اتصال یک پلتفرم (مثلاً بله)، دکمه «اتصال ربات» از پروفایل سایت **کاملاً حذف می‌شد** و امکان اتصال تلگرام باقی نمی‌ماند! حالا هر پلتفرم دکمه و وضعیت جداگانه دارد: «🔗 اتصال تلگرام» و «🔗 اتصال بله» — می‌توانی یکی را وصل کنی و بعداً دیگری را. بعد از اتصال هر دو، پیام تبریک نمایش داده می‌شود
2. **🧠 دستور /link هوشمند شد** — اگر از پلتفرمی که از قبل متصل است /link بزنی، به‌جای کد بی‌فایده، راهنمایی می‌گیری: «حسابت از قبل متصل است ✅» + راهنمای اتصال پلتفرم دیگر. پیام خطای کد تکراری هم شفاف شد
3. **🏷 نشان نسخه سرور** — پایین سایت نسخه Worker نمایش داده می‌شود (مثل `v1.4.0`) تا همیشه مطمئن باشی کد جدید واقعاً دیپلوی شده

### نسخه ۱.۲ (قبلی)

1. **🎨 انیمیشن‌های سایت** — هیرو با زوم سینمایی و ورود پله‌ای، reveal-on-scroll، شمارنده متحرک آمار، جلوه براقی دکمه‌ها، بلند شدن کارت‌ها، ورود فنری پله‌ای اسلات‌ها + تنفس اسلات‌های آزاد + درخشش اسلات خودت، زیرخط لغزان منو، نوار پیشرفت روباه‌ای — همه با احترام به `prefers-reduced-motion`
2. **👥 رفع باگ ظرفیت** — سقف تیم‌ها از ۱۰ به **۵۰** رسید (۲۵ تیم دو نفره = ۵۰ نفر ✓). Clamp بی‌صدا حذف شد؛ خطاها با پیام واضح برگردانده می‌شوند. پیش‌نمایش زنده «تیم × نفر = بازیکن» در مودال ساخت روم + در ویزارد ربات. سقف کل هر روم ۲۵۰ بازیکن
3. **📸 عکس رسید الزامی، کد پیگیری اختیاری (در هر دو ربات)** — کاربر باید عکس رسید واریز را بفرستد (کد پیگیری اختیاری — می‌تواند در کپشن عکس باشد). عکس مستقیماً برای ادمین‌ها ارسال می‌شود با دکمه تایید/رد روی همان عکس؛ ادمین پلتفرم دیگر پیام راهنما می‌گیرد. دکمه «📸 دیدن رسید» در لیست پرداخت‌ها. مهاجرت دیتابیس خودکار است — نیازی به SQL دستی نیست

## ✨ امکانات

### 🌐 سایت (GitHub Pages)
- طراحی جذاب با تم اختصاصی کالاف دیوتی موبایل (نارنجی/سیاه نظامی)
- هیرو با بنر اختصاصی + آمار زنده پلتفرم
- لیست روم‌ها با فیلتر (حالت بازی، وضعیت)
- **اسلات‌مپ زنده**: انتخاب موقعیت دقیق در تیم‌ها (تیم آ، ب، ج...)
- نمایش بازیکنان قطعی هر روم
- پروفایل: کیف پول، روم‌های من، جوایز، تراکنش‌ها
- اتصال اکانت سایت به ربات با کد
- **پنل ادمین کامل**: داشبورد آمار، ساخت/ویرایش روم، تایید پرداخت‌ها، جوایز، کاربران، تنظیمات، پیام همگانی

### 🤖 ربات تلگرام + ربات بله (منطق مشترک)
- منوی کامل: روم‌ها، حساب من، شارژ کیف پول، جوایز، راهنما
- انتخاب روم → انتخاب اسلات → پرداخت (کیف پول / کارت به کارت / درگاه)
- فرم ساخت روم مرحله‌به‌مرحله برای ادمین (۹ مرحله)
- تایید/رد پرداخت‌ها و جوایز از داخل ربات
- ارسال Room ID و رمز به همه بازیکنان قطعی با یک دستور
- اعلان خودکار: پرداخت جدید، تایید پرداخت، شروع روم، لغو روم + بازگشت وجه
- تنظیمات کامل از داخل ربات (توکن‌ها، کارت، درگاه، سایت، ...)
- پیام همگانی دسته‌ای (ضد محدودیت subrequest)

### 💰 سیستم مالی
- کیف پول داخلی با تراکنش‌های قابل رهگیری
- کارت به کارت + درگاه آنلاین (اگر تنظیم نشوند، دکمه‌شان **خودکار مخفی می‌شود**)
- جوایز نقدی با تایید ادمین
- بازگشت وجه خودکار در لغو روم / حذف بازیکن

### 🎮 حالت‌های روم (پیش‌فرض)
`TDM 5v5` • `S&D 4v4` • `S&D 6v6` • `DOM 5v5` • `گانفایت 2v2` • `1v1` • `اسنایپر` • `چاقو` • `بتل رویال (۴ اسکواد)` • `سفارشی` — ادمین می‌تواند هر چیدمان دلخواه بسازد (۲ تا ۱۰ تیم، ۱ تا ۲۰ نفر).

## 🚀 نصب گام‌به‌گام (۵ دقیقه)

### ✅ وضعیت فعلی (از قبل آماده)
- ☁️ ورکر شما: `https://codm-room.4-k5bbin1ys6uuriq0ud2nrhdph4-p.workers.dev` (با D1 متصل — هر نامی که Bindng داشته باشد خودکار شناسایی می‌شود)
- ⚙️ `docs/config.js` از قبل به همین آدرس تنظیم شده
- 🗄 **جداول D1 خودکار ساخته می‌شوند** — نیازی به اجرای دستی schema.sql نیست!

### گام ۱ — دیپلوی کد Worker
1. محتوای فایل [`worker/worker.js`](worker/worker.js) را کپی کن
2. در [dash.cloudflare.com](https://dash.cloudflare.com) → Workers → ورکر `codm-room` → **Edit code** → کل کد را جایگزین کن → **Deploy**
3. آدرس ورکر را باز کن — باید «🪖 CODM Rooms Platform v1.1» و ✅ اتصال D1 را ببینی
   - در اولین درخواست، همه جداول + تنظیمات پیش‌فرض + کلید امنیتی وب‌هوک خودکار ساخته می‌شوند

### گام ۲ — اتصال دو ربات
1. با ربات تلگرام یا بله‌ات `/start` بزن — **اولین نفر = مدیر اصلی** 🛡
2. در «🛡 پنل مدیریت» ← «⚙️ تنظیمات» ← توکن ربات‌ها، شماره کارت، درگاه و... را ثبت کن
   (یا از سایت: پنل مدیریت → تنظیمات)
3. وب‌هوک‌ها را وصل کن — دو راه:
   - سایت ← پنل مدیریت ← تنظیمات ← دکمه **اتصال خودکار وب‌هوک‌ها**
   - یا صفحه `https://...workers.dev/setup` ← توکن ادمین سایت + دکمه اتصال

> 🔒 وب‌هوک‌ها با **کلید امنیتی خودکار** تنظیم می‌شوند (`/tg/<secret>` و `/bale/<secret>`) تا هیچ‌کس نتواند پیام جعلی به ربات بفرستد.

### گام ۳ — سایت
- فایل `docs/config.js` از قبل تنظیم شده — فقط GitHub Pages را روشن کن (Settings → Pages → Deploy from branch → `main` + `/docs`)
- اگر روزی آدرس ورکر عوض شد، همان‌جا تغییرش بده

### گام ۴ — شروع!
- سایت: ثبت‌نام ← اولین حساب = ادمین
- روم بساز (سایت یا هرکدام از ربات‌ها — همه یک دیتابیس مشترک دارند)
- بازیکن‌ها اسلات انتخاب می‌کنند ← پرداخت ← تایید تو ← قطعی 🎮

## 🧪 تست‌شده و بی‌نقص

این نسخه با **۱۵۵ تست خودکار End-to-End** روی یک D1 واقعی (SQLite) تایید شد:
اتو-ساخت جداول، ثبت‌نام/ورود، ساخت روم در هر ۳ پلتفرم، انتخاب اسلات، هر ۳ روش پرداخت (کیف پول/کارت/درگاه)، تایید/رد ادمین، بازگشت وجه خودکار (لغو روم/حذف بازیکن/انصراف)، جوایز، اتصال اکانت ربات↔سایت، ماسک شدن Room ID/Pass از غیرقطعی‌ها، کلید امنیتی وب‌هوک، هر ۹ مرحله ویزارد ساخت روم ربات، پیام همگانی و مسدودسازی کاربر — به‌علاوه تست‌های جدید: روم ۲۵×۲=۵۰ نفره، خطاهای سقف‌ها، جریان کامل عکس رسید (ذخیره، ارسال به ادمین هم‌پلتفرم، راهنمای پلتفرم دیگر، کپشن به‌عنوان کد اختیاری، تایید و اعتبار کیف پول) و **درگاه پرداخت ربات** (ساخت خودکار لینک از توکن، جریان `pay_` در هر دو ربات، جلوگیری از تصاحب پرداخت دیگران، راهنمای اتصال برای مهمان‌ها، کش username و اعتبارسنجی آن).

## 🔌 API (برای توسعه‌دهندگان)

| متد | مسیر | توضیح |
|-----|------|-------|
| GET | `/api/health` | سلام سرویس |
| GET | `/api/public/stats` | آمار عمومی |
| GET | `/api/rooms` | لیست روم‌ها |
| GET | `/api/rooms/:id` | جزئیات روم + اسلات‌ها |
| POST | `/api/register` `/api/login` | ثبت‌نام / ورود |
| POST | `/api/rooms/:id/join` | رزرو اسلات |
| POST | `/api/rooms/:id/leave` | انصراف + بازگشت وجه |
| POST | `/api/topup` | درخواست شارژ |
| POST | `/api/payments/:id/approve` | تایید پرداخت (ادمین) |
| POST | `/api/prizes` | دادن جایزه (ادمین) |
| POST | `/api/broadcast` | پیام همگانی دسته‌ای (ادمین) |
| POST | `/api/webhook/set` | اتصال خودکار وب‌هوک (ادمین) |
| POST | `/tg/<secret>` و `/bale/<secret>` | وب‌هوک ربات‌ها (با کلید امنیتی) |
